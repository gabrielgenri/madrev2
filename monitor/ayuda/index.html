Ayuda de MonitorV3.2 y Biblioteca riojana

Guía para implementar y utilizar el monitor de noticias de La Rioja y vincularlo con la Biblioteca riojana.

Publicación en GitHub Pages

  1. Conservá la estructura de carpetas: index.html, data/, scripts/ y ayuda/.
  2. En el repositorio madrev2, la app debe quedar dentro de monitor/. La dirección esperada es /madrev2/monitor/.
  3. En la configuración de Pages, publicá desde la rama main y la carpeta raíz del repositorio. La página principal del repositorio debe conservarse.
  4. Esperá a que termine el despliegue y abrí la app. Los datos se leen con rutas relativas desde monitor/data/.

El flujo de GitHub Actions incluido en .github/workflows/ está copiado dentro de esta carpeta. GitHub solo ejecuta flujos ubicados en el .github/workflows/ de la raíz del repositorio; para automatizar la recolección en madrev2, hay que instalar allí un flujo adaptado a las rutas monitor/.

Biblioteca riojana: unir actualidad y fichas

La Biblioteca trabaja con fichas explicativas atemporales; Monitor reúne noticias y documentos de actualidad. El panel de integración permite consultar las noticias desde la Biblioteca y usar una nota como referencia para preparar un borrador de contexto.

  1. Copiá integracion-biblioteca/monitor-biblioteca.js al repositorio de El Independiente, en ecosistema/assets/js/biblioteca/.
  2. Agregá en ecosistema/biblioteca/index.html, después del módulo de Biblioteca, <script type="module" src="../assets/js/biblioteca/monitor-biblioteca.js"></script>.
  3. Publicá el repositorio. La pestaña Monitor mostrará búsqueda, filtros temáticos y el enlace a cada noticia original.
  4. Con sesión editorial activa, Preparar borrador de contexto crea una ficha en estado borrador con el título de trabajo y la referencia. Completá la explicación atemporal y verificá los datos antes de enviarla a revisión.

El módulo lee noticias desde el JSON público de Monitor y no escribe en Monitor. Las categorías se asignan como sugerencia; revisá la categoría, el departamento y el contenido antes de avanzar el estado editorial.

La guía detallada está en Integración de Monitor en Biblioteca riojana.

Fuentes técnicas incorporadas

  • MonitorV1: arquitectura del crawler, RSS y archivos; el catálogo de sitios sirve como antecedente del esquema actual.
  • MonitorV2: catálogo de 53 sitios, límites de ejecución y limpieza de procesos. El workflow V3.2 del ZIP mantiene su propio cron de cuatro horarios UTC.
  • MonitorV3.2: los JSON y el recolector actuales son la base operativa del panel integrado.
  • RSSv3: aporta taxonomías y extracción completa como referencias; el panel muestra noticias y fuentes sin trasladar síntesis de actualidad a fichas atemporales.
  • README y dependencias: explican la estructura local y las bibliotecas Python requeridas.

Uso de la aplicación

  • Notas: buscá por título, palabra clave o fuente; filtrá por taxonomía y abrí la noticia original.
  • Fuentes: consultá el estado de cada sitio y sus notas. Podés agregar, editar, pausar o eliminar fuentes.
  • Vinculado: revisá contenidos relacionados entre distintas notas.
  • Etiquetas: explorá las taxonomías y etiquetas más frecuentes.
  • Actualizar: vuelve a cargar los JSON publicados. Los cambios del catálogo hechos desde el navegador se guardan en ese navegador.

Los cambios de fuentes se almacenan en localStorage del dispositivo y navegador actuales; no se sincronizan con GitHub ni con otros usuarios. Usá «Exportar JSON» para guardar una copia del catálogo local.

Estructura y mantenimiento

  • data/monitor_v3_fuentes.json: catálogo y configuración de fuentes.
  • data/monitor_v3_noticias.json: noticias, contenidos vinculados y archivos detectados.
  • scripts/monitor_v3_recolector.py: recolector RSS/Atom y rastreo web.
  • requirements.txt: dependencias Python del recolector.

Para cambiar datos publicados, actualizá los JSON en el repositorio y esperá el nuevo despliegue de Pages. Para probar la interfaz en local, serví la carpeta con un servidor HTTP; abrir el HTML directamente puede impedir la carga de los JSON por las restricciones del navegador.
